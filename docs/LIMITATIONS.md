# Limitations

- Windows policy, UAC, endpoint security, WMI permissions, drivers, and network policy can limit diagnostics or repairs.
- The built-in AI layer is an interface and safety boundary; no network provider is bundled.
- Repair coverage is deliberately limited to approved workflows.
- Disk health is capacity-oriented; SMART/device-driver remediation is not implemented.
- Reports contain collected evidence only and may omit unavailable diagnostics.
