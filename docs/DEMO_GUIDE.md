# Demo guide

Open **Demo Lab** from the sidebar. Every scenario is visibly marked simulated and can export a simulated report.

1. **DNS resolution failure**: show DNS evidence, `network_flush_dns`, simulated verification, and report.
2. **Print Spooler stopped**: show the printer finding and controlled Spooler recommendation.
3. **Unresolved escalation**: run the unresolved scenario to show bounded fallback and escalation guidance.

Low disk-space and high-CPU scenarios demonstrate non-destructive evidence and approved recommendations. No demo performs a real system repair.
